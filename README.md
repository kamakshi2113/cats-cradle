# Neon Cat's Cradle

A digital take on the classic string game. Hold both hands up to your webcam and glowing neon strings stretch between your fingertips. Pull your hands apart and the strings tighten, thin out, change colour and start to vibrate.

**Live demo:** https://kamakshi2113.github.io/cats-cradle/

## How to use
1. Open the live demo in Chrome, Edge or Safari.
2. Click **Enable camera** and allow access.
3. Raise both hands.

Video is processed locally in your browser. Nothing is uploaded.

## Controls
- `W`: switch to the crossed "weave" string pattern
- `H`: hide the on-screen text

## Built with
HTML, CSS, JavaScript · [p5.js](https://p5js.org/) · [MediaPipe Hands](https://developers.google.com/mediapipe)

## Run locally
It's a single `index.html` file. Open it in a browser, or run `python3 -m http.server` in this folder and visit `http://localhost:8000`.
